# 介護タクシー 料金シミュレーター＆LINE申込

住所を2つ入れると距離から概算料金を自動計算し、そのままLINEで申し込みを送れるシステムです。
WordPress に依存しない独立した PHP アプリなので、WP サイトにも静的サイトにも同じタグで埋め込めます。
データベースは不要です（`data/` フォルダに JSON で保存します）。

## 全体の流れ

```
お客様（サイト上）                         事業者
 ① 住所・片道/往復・オプション入力
 ② 「料金を計算する」→ 距離と概算料金を表示
 ③ 日時・氏名・電話などを入力
 ④ 「内容を確定してLINEで送る」
     → 申込番号を発行・サーバーに保存 ──→ 管理画面の申込一覧に表示（＋通知メール）
 ⑤ LINEが開き、申込内容が入力済み
     → お客様が送信 ─────────────────→ LINE公式アカウントのチャットに届く
                                          ⑥ 空き状況を確認し、LINEで手動返信
                                             （クレカ希望なら Square の決済リンクを送る）
```

- 予約はこの時点では確定しません。画面にも「まだ確定していない」と表示しています。
- お客様がLINEの文面を書き換えても、管理画面の料金はサーバーで計算した値なので、申込番号で照合できます。

## フォルダ構成

```
kaigo-taxi-simulator/
├── config.sample.php  設定のひな型 → config.php にコピーして使う
├── api.php            ウィジェットが呼ぶAPI（料金計算・申込）
├── index.php          動作確認用ページ
├── assets/
│   ├── widget.js      埋め込みウィジェット本体
│   └── widget.css     最小限のデザイン（サイト側で上書き・差し替え可）
├── admin/             管理画面（申込一覧・料金設定・料金テスト）
├── lib/               処理本体（Webからは見えない）
└── data/              設定・申込データの保存先（Webからは見えない）
```

## 設置手順（Xserver）

### 1. ファイルをアップロード
1. `config.sample.php` をコピーして `config.php` を作り、最低限 `admin_password` を変更する。
2. `kaigo-taxi-simulator` フォルダごと、サイトのドキュメントルートにアップロードする。
   例: `/ドメイン名/public_html/kaigo-taxi-simulator/`
   - WordPress が同じドメインにあっても、実在するフォルダは WP より優先されるので問題ありません。
3. `https://ドメイン/kaigo-taxi-simulator/` を開いてシミュレーターが表示されればOK。
4. `https://ドメイン/kaigo-taxi-simulator/admin/` にログインして、料金を設定する。

PHP 8.0 以上が必要です（Xserver のサーバーパネル「PHP Ver.切替」で確認）。

### 2. テストモードで試す
`config.php` の `'mock_distance' => true` の間は Google を使わず、住所から作ったダミー距離で計算します。
画面の上に「テストモード」と表示されます。料金設定や申込の流れを確認するのに使ってください。
管理画面の「料金テスト」では、距離(km)を直接入れて料金を確認することもできます。

### 3. Google Maps（距離の自動計算）を有効にする
1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作り、請求先アカウントを設定する。
2. 「APIとサービス」→「ライブラリ」で **Routes API** を有効にする。
3. 「認証情報」で APIキーを作成し、次の制限をかける（不正利用で課金されないように）。
   - アプリケーションの制限: **IPアドレス** → Xserver のサーバーのIPアドレス
     （サーバーパネル「サーバー情報」の「IPアドレス」）
   - APIの制限: **Routes API** のみ
4. `config.php` に `'google_maps_api_key' => 'キー'` を入れ、`'mock_distance' => false` にする。

- APIキーはサーバー側（PHP）だけで使い、ブラウザには出ません。
- 同じ区間の結果は1日キャッシュし、1つのIPから1時間に計算できる回数も制限しています（`config.php` で変更可）。
- 費用は使った分だけかかります。小規模な事業者のアクセス数なら、月ごとの無料利用枠に収まる見込みです。念のため Google Cloud で予算アラートを設定してください。

### 4. LINE を設定する
管理画面の「料金・設定」で、**LINE公式アカウントのベーシックID**（`@` から始まるID）を入力してください。
LINE Official Account Manager の「設定」→「アカウント設定」で確認できます。

この方式は LINE の API 設定（チャネルやトークン）が要らず、お客様のLINEで申込内容が入力済みのトーク画面を開くだけです。
お客様がそのまま送信すると、公式アカウントのチャットに届きます（チャット機能をオンにしておいてください）。

### 5. サイトに埋め込む
表示したい場所に次の2行を貼ります。WordPress なら「カスタムHTML」ブロックに貼ってください。

```html
<div id="kaigo-taxi-sim"></div>
<script src="https://ドメイン/kaigo-taxi-simulator/assets/widget.js" defer></script>
```

| scriptタグに付けられる属性 | 内容 |
|---|---|
| `data-target="#xxx"` | 表示先を変える（既定は `#kaigo-taxi-sim`） |
| `data-api="https://.../api.php"` | APIの場所を変える（既定は widget.js と同じ設置場所） |
| `data-no-css` | widget.css を読み込まない（サイト側で一からデザインする場合） |

- 別のドメインのサイトに埋め込む場合は、`config.php` の `allowed_origins` にそのサイトのURLを追加してください。
- デザインを直すときは、`.kts-` から始まるクラスを上書きしてください。色は `.kts` の CSS変数（`--kts-accent` など）でも変えられます。

## 管理画面でできること

| 画面 | 内容 |
|---|---|
| 申込一覧 | 申込の一覧、ステータス（新規／対応中／受付確定／お断り／キャンセル）での絞り込み |
| 申込詳細 | 申込内容・料金内訳・地図リンク、ステータスと社内メモの更新 |
| 料金・設定 | 運賃（初乗り＋加算 または 距離帯ごとの固定料金）、迎車料金、端数処理、上限距離、往復、有料道路を使うかどうか、オプション、選択肢、LINE ID、通知メール、注意書き |
| 料金テスト | 距離または住所を入れて、今の設定での料金を確認 |

### 料金の計算方法
- **初乗り＋加算方式**: 初乗り距離までは初乗り運賃。超えた分は加算距離ごとに加算運賃（タクシーメーターと同じく、加算距離に満たない端数も1回分として数える）。
- **距離帯方式**: 「〇kmまで〇円」の表で、当てはまる行の料金。
- 往復は片道運賃×2。その後に迎車料金とオプションを足し、端数処理をした金額が概算料金になります。
- 片道の距離が上限距離を超えると、料金は出さずに「LINEで相談」のボタンを表示します。

## セキュリティ
- `config.php`・`lib/`・`data/` は `.htaccess` でWebから見えないようにしています。
- 料金はサーバー側で必ず計算し直すので、画面を改ざんされても料金は変わりません。
- 管理画面は、パスワードログイン・ログイン試行回数の制限・CSRF対策をしています。
- 申込には健康状態に関する情報も含まれるため、プライバシーポリシーのURLを設定してください。

## 今後の拡張候補
- **LIFF／LINEログイン**: お客様のLINEユーザーIDと申込を紐づければ、管理画面から決済リンクなどを自動で送れるようになります。
- **Square 決済リンク**: 管理画面の「受付確定」と同時に Square の決済リンクを発行する（今は手動で送る運用）。
- **住所の入力補完**（Google Places）。
